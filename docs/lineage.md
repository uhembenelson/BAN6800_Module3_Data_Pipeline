# Data Lineage - gold_customer_profile

Generated by `src/lineage.py` on every pipeline run. Do not edit by hand.

## Source

- **System:** P6 UK Bank Customer Profile Data
- **Format:** CSV (4,014 records)
- **Frequency:** annual snapshot (2015); monthly in production

## Stages

`ingestion` -> `augmentation` -> `anonymisation` -> `cleaning` -> `transformation` -> `integration` -> `validation`
