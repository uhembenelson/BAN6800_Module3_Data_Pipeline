# Model Card Template

## Intended use

Describe the approved users, business decision, and human-review requirements.

## Data

Document source periods, inclusion criteria, label definition, exclusions, and known gaps.

## Performance

Report AUC, recall in the highest-risk decile, calibration, and confidence intervals.

## Fairness

Report demographic-parity ratio, equal-opportunity gap, and calibration gap across gender, age band, and region.

## Explainability

Provide local SHAP explanations for advisers and global SHAP analysis for governance reviewers.

## Limitations and monitoring

Record unsuitable uses, drift thresholds, retraining gates, escalation owners, and retirement criteria.
